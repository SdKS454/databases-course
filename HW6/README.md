# Домашняя работа 6 — Подзапросы, CTE и оконные функции

**Предметная область:** Dota 2

**Схема данных:** `nf` из HW3. Проверено на PostgreSQL 16.15.

Работа состоит из двух частей по презентациям «08. Подзапросы» и
«09. CTE, Оконные функции».

| Часть | Отчёт | SQL | Количество |
|---|---|---|---:|
| Подзапросы | [sub_queries.md](sub_queries.md) | [queries.sql](queries.sql) | 23 |
| CTE, операции множеств и оконные функции | [cte_union_window.md](cte_union_window.md) | [cte_queries.sql](cte_queries.sql) | 21 |

## Порядок выполнения в pgAdmin

1. Открыть Query Tool базы со схемой `nf`, подготовленной для HW5.
2. Выполнить запросы из `queries.sql` на исходных данных HW2–HW3.
3. Выполнить **целиком** [cte_demo_data.sql](cte_demo_data.sql): он добавляет
   демонстрационные строки для второй части. Повторный запуск не дублирует строки.
4. Выполнить запросы из `cte_queries.sql`. После добавления демонстрационных данных
   каждый из 21 запроса возвращает непустой результат.

Запросы удобно выделять и выполнять по номерам. Файлы запросов только читают
данные, используют явные имена схемы `nf` и не содержат команд psql.
Скрипт `cte_demo_data.sql` добавляет данные в транзакции без изменения старых строк.
После него результаты первой части могут отличаться от исходного вывода,
поскольку изменились набор игроков, матчей и статистика.

Если база ещё не подготовлена, использовать отдельную учебную базу и выполнить:

1. `SET search_path TO public;`, затем [HW2/create_tables.sql](../HW2/create_tables.sql).
2. [HW2/alter_tables.sql](../HW2/alter_tables.sql).
3. [HW2/insert_data.sql](../HW2/insert_data.sql).
4. [HW2/update_data.sql](../HW2/update_data.sql).
5. [HW3/normalized_schema.sql](../HW3/normalized_schema.sql).
6. [HW3/migrate_to_nf.sql](../HW3/migrate_to_nf.sql).

Эти подготовительные скрипты пересоздают объекты; повторять их в уже заполненной
базе для выполнения HW6 не нужно. Особенность переноса ID предметов в HW3
описана в `sub_queries.md`; старые работы в HW6 не изменялись.

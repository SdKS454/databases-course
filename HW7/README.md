## Как устроены опыты

Использую нормализованную схему `nf` из HW3 и данные после HW6.
Для экспериментов добавляю отдельные строки `HW7_TX_` и не меняю исходные записи.
T1 и T2 — независимые соединения с одной базой. Взаимодействие выполняю
строго по пронумерованным шагам: полный запуск одного T1.sql перед T2.sql
не воспроизводит нужное чередование.

## Главный вывод

COMMIT и ROLLBACK управляют сохранением всей транзакции, SAVEPOINT — частичным
откатом. Уровень изоляции определяет видимость чужих изменений и допустимость
конфликтов. Ошибку сериализации я обрабатываю повтором всей транзакции,
а не продолжением уже прерванной.

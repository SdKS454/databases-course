# Dota 2 Database

## Описание проекта

Проект посвящён проектированию базы данных для киберспортивной дисциплины **Dota 2**. Предметная область охватывает профессиональные и любительские матчи, игроков и команды, героев, предметы, а также индивидуальную статистику выступлений: киллы, смерти, ассисты, заработанное золото и опыт.

База решает проблему разрозненности данных о матчах: вместо того чтобы хранить информацию о каждой игре в отдельных таблицах или текстовых логах, единая схема позволяет в удобном виде хранить историю матчей, связывать их с игроками и героями, а затем анализировать результаты — например, находить сильнейших игроков на конкретном герое или команды с лучшей статистикой в турнирах.

## Содержимое домашних работ

### HW1 — Проектирование базы данных
- **Сущности**: Players, Teams, Matches, Heroes, Items, PlayerMatchStats, PlayerMatchItems
- **ER-диаграмма** в нотации Crow's Foot (см. `HW1/ER_diagram.png`)
- **SQL-схема** для PostgreSQL (см. `HW1/README.md`)
- **2 запроса на реляционной алгебре**: с операциями σ и π; с операцией соединения ⋈

### HW2 — Работа с таблицами в PostgreSQL
- **CREATE TABLE** — 7 таблиц по ER-диаграмме
- **ALTER TABLE** — 5 запросов изменения структуры
- **INSERT** — 4–5 тестовых записей в каждую таблицу
- **UPDATE** — 5 запросов изменения данных
- **Скриншоты** структуры — текстовый вывод psql в `HW2/output/`
